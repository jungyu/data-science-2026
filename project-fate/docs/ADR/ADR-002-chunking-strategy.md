# ADR-002：採用語意感知的遞迴分塊策略

## 背景

JR Pass 官方規則文件包含票券資格、區域覆蓋、有效天數、列車限制、FAQ 與更新公告等內容。  
若 chunk 切分策略不佳，會造成：

- 規則上下文被切斷
- 檢索到的片段過短，無法支撐 citation
- 不同條件被錯誤拆開，降低合規判定可信度

本次評估的切分策略包括：

- 固定長度分塊（fixed-size）
- 語意分塊（semantic chunking）
- 遞迴式分塊（recursive chunking）

在規則文件測試中，語意感知的遞迴分塊在檢索品質與上下文保留之間取得較佳平衡。

## 決策

本專案採用語意感知的遞迴分塊策略。

具體原則如下：

1. 優先依段落與結構邊界切分。
2. 若段落過長，再依句子或片語細分。
3. 避免以機械式固定長度直接截斷完整規則。
4. 目標 chunk 大小約為 600 tokens。
5. chunk overlap 約為 100 tokens，以保留相鄰規則的上下文。

## 狀態

Accepted

## 後果

### 正面影響

- 規則上下文保留較完整
- 提高 retrieval 與 citation 的可用性
- 有助於後續的合規判定與 grounding 檢查

### 負面影響

- 切分流程比固定長度策略更複雜
- 需要更完整的 metadata 與結構解析

### 後續影響

- ingestion pipeline 需保留段落邊界與來源結構資訊
- 評估流程需觀察不同 chunk 大小是否影響 Top-K accuracy 與 latency
